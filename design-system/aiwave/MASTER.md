# AIWave design system

> 本文件整合 `ui-ux-pro-max` 的可用性規則與本專案已核准的 LearnHub 視覺語言。
> 若規則衝突，以 `docs/brand-spec.md`、`docs/specs/08-product-experience.md` 與 WCAG 2.2 AA 為準。

## Product character

- 定位：可代替會員理解、規劃並執行跨服務生活任務的 AI 生活管家，不是第二個 OPENPOINT。
- 感受：溫暖、可信、清楚、有行動感；避免常見 AI 紫色、玻璃擬態與裝飾性漸層。
- 品牌基底：奶油背景、白色卡片、深墨粗框、硬偏移陰影、綠色主行動與低飽和粉彩分類色。
- 字型：Nunito、Noto Sans TC、Microsoft JhengHei；中文內文不得使用手寫字型。

## Authoritative tokens

| Role | Value | Usage |
| --- | --- | --- |
| Background | `#FFF9F5` | 全站底色 |
| Surface | `#FFFFFF` | 卡片、對話區、表單 |
| Ink | `#2D3748` | 文字、3px 邊框、焦點環、硬陰影 |
| Muted | `#5A6478` | 輔助文字，仍須維持 4.5:1 |
| CTA | `#22C55E` | 主要按鈕底色，搭配 Ink 文字 |
| Link green | `#15803D` | 文字連結與狀態文字 |
| Peach | `#FDBCB4` | 品牌標記與柔和強調 |
| Baby blue | `#ADD8E6` | 次要操作與資訊狀態 |
| Mint | `#98FF98` | 目前頁、成功與建議 |
| Lavender | `#E6E6FA` | 非關鍵分類色 |

- 卡片：`3px solid #2D3748`、`24px` 圓角、`6px 6px 0 #2D3748` 硬陰影。
- 按鈕：至少 `44×44px`、`3px` 邊框、`16px` 圓角、`4px 4px 0` 硬陰影。
- 間距使用 4/8 節奏；內文至少 16px；觸控目標不得低於 44px。

## Information architecture

會員主導覽固定為五項，順序與名稱不可改動：

1. 首頁
2. 點數兌換
3. AI
4. 服務
5. 會員中心

- 桌面版置於頂部；手機版同一組語意導覽固定於底部，不能產生兩套重複可聚焦連結。
- 訂單、群組／家庭／社區是會員中心或首頁的次層入口，不佔主導覽。
- 手機內容需預留底部導覽、安全區與鍵盤空間，不得遮住最後一個操作。

## Home reading order

登入後首頁依序呈現：

1. OPENPOINT 展示點數與本月消費摘要
2. 待處理事項
3. 輕量 AI 任務入口
4. 個人化推薦
5. 常用功能
6. 優惠內容

每一塊都必須有可執行下一步；不得以無法點擊的條列假裝功能。

## AI interaction

- AI 是獨立全頁工作區；訊息區自行捲動，輸入框固定在工作區底部。
- 使用者訊息靠右、AI 靠左；建議選項以可鍵盤操作的按鈕列放在輸入框上方。
- textarea 禁止手動拖曳，依輸入換行自動增高並設最大高度。
- streaming 顯示「理解需求／查詢服務／準備方案」等可驗證狀態與工具摘要。
- 不揭露原始 chain-of-thought；可提供簡短的決策依據、資料來源與下一步。
- 讀取與導覽可自動；設定與表單需預覽確認；交易、兌換、下單、取消必須明確確認。

## Accessibility and behavior

- 遵循 WCAG 2.2 AA：一般文字 4.5:1、粗大文字 3:1、非文字元件 3:1。
- 每頁恰有一個清楚的 `h1`，標題階層不可跳級。
- 所有圖示按鈕需有 accessible name；結構性導覽圖示使用同一套 SVG，不以 emoji 代替。
- 不以 hover 才揭露關鍵操作；鍵盤、觸控與滑鼠必須等價。
- 所有焦點都有 3px Ink 外框；路由切換後把焦點移到主要內容。
- 尊重 `prefers-reduced-motion`；任何 streaming 或進度動畫都要有靜態狀態文字。
- sticky/fixed 元件不得遮住錨點、標題、聊天輸入框或頁尾內容。
- 驗證寬度：375、768、1024、1440px；禁止水平捲動。

## Avoid

- 通用 AI 紫／粉漸層、玻璃擬態、手寫標題與只有裝飾沒有資訊的 hero。
- 以假資料暗示真實 OPENPOINT 即時餘額；展示資料須清楚標註來源。
- 把推薦卡做成全部一起關閉；「不感興趣」只影響該項並能回復。
- 將所有服務一次平鋪成無優先順序的目錄。
- 顯示無法操作的選項、死連結或沒有結果回饋的按鈕。

- [ ] 首頁閱讀順序符合規格，且每區有下一步
- [ ] AI 輸入框固定、可自動增高、支援鍵盤與螢幕閱讀器
- [ ] 所有互動目標至少 44px，焦點清楚
- [ ] reduced-motion、對比、標題階層、ARIA 與表單標籤通過稽核
- [ ] 展示資料、推論資料、真實資料的來源標示沒有混淆
