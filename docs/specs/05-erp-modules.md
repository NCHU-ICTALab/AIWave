# 05・Web 產品模組與角色入口

> 狀態：現行模組基線  
> 更新日期：2026-07-28  
> 前一版本已封存至 [archive](../archive/superseded/2026-07-28/specs/05-erp-modules.md)。

## 1. 入口與身分

| 入口 | 身分 | 說明 |
| --- | --- | --- |
| `/login` | 未登入 | 模擬 uniopen identity adapter；正式 OIDC 只替換 adapter |
| `/user/*` | 會員 | 首頁、點數、AI、服務、會員中心及訂單 |
| `/partner/*` | 合作廠商人員 | 需求、報價、聯繫、履約與接入狀態 |
| `/platform/*` | 平台營運者 | 契約、connector、服務缺口與稽核；不在會員導覽 |

不存在一般使用者可見的「切換工作區」或「重設 Demo」。Demo 切換角色等同使用不同種子帳號重新登入。

## 2. 會員端

### 首頁

- 點數、本月消費、待處理事項與近期進度。
- 輕量 AI 交辦；送出後進全頁 AI 並保留訊息。
- 可解釋推薦、逐張不感興趣／復原、常用功能及標示清楚的活動。

### 點數兌換

- 點數帳本、即將到期、優惠券與兌換紀錄。
- 確定性折抵／累點試算與方案比較。
- 高影響兌換必須預覽及確認。

### AI

- 全頁聊天、固定底部輸入、內部訊息捲動、串流進度及工具摘要。
- Planner 依 capability registry 產生多步驟 task plan。
- 可導覽、預填、試算、媒合及經確認後執行交易。

### 服務

- 搜尋、分類、情境、常用及替代方案。
- 每個項目都有方案、題組、諮詢、訂單或追蹤等真實後續。
- 媒合結果可比較地區、時段、預算、緊急度、範圍、評分及點數。

### 會員中心

- 個人、地址、聯絡、偏好、禁忌、個人化同意及通知。
- 家庭、情侶、宿舍與社區群組；管理 role、active scope 及共享授權。
- 訂單分組折疊與完整履約時間軸。

## 3. 合作廠商端

| 模組 | 功能 |
| --- | --- |
| 需求佇列 | 新諮詢、服務分類、AI 摘要、聯絡授權與 SLA |
| 案件詳情 | 原始題組答案、附件、地區、時段、預算及緊急程度 |
| 報價 | 方案、分項、總額、有效期限、可用時段及備註 |
| 履約 | 接單、排程、到場、完成、異常與回覆紀錄 |
| 接入 | OpenAPI 版本、Client 模式、健康度、最後同步及遮罩憑證 |

AI 可協助產生摘要、回覆或報價草稿；送出、拒單、改價及狀態更新仍需有權人確認。

## 4. 平台營運端

- 官方服務來源與合作廠商分開管理。
- Vendor contract、schema 版本、欄位映射及健康檢查。
- fake／real adapter 狀態、延遲、失敗率、降級與稽核。
- 未匹配需求、低信心意圖及未滿足地區／時段彙整成服務缺口情報。
- Web、AI、MCP 的同一 capability 覆蓋狀態。

## 5. Group 能力

Group 不是獨立社區 App；由會員端依 active scope 進入：

- family：代辦、共享提醒、安心通知與共同生活任務。
- couple／dorm：共享清單、分帳、團購及共同排程。
- community：聯合服務、團購、活動及經授權的社區資訊 connector。

群組管理者只能看到完成群組任務必要的資料，不能讀取成員個人行為特徵檔。

## 6. 共用元件

- `ConversationShell`：串流訊息、固定 composer、選項、進度與錯誤恢復。
- `PermissionPreview`：設定、表單、交易與群組共享的變更摘要。
- `VendorComparison`：方案、理由、限制、價格、時段及選擇。
- `PointSimulation`：點數／優惠試算與來源。
- `OrderAccordion`：狀態分組、摘要及履約時間軸。
- `ScopeSwitcher`：清楚顯示目前 individual／group 上下文。
- `SourceBadge`：官方、競賽 seed、平台狀態及降級來源。

所有共用元件需符合 [08 產品體驗](08-product-experience.md)及 WCAG 2.2 AA。
