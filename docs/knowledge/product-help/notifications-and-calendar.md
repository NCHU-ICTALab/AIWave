# 通知與行事曆

## 目前可用功能

訂單、任務、提醒、Group／Community 與手動事件可以投影到 AIWave 行事曆。交易狀態與通知由同一份履約事件更新，取消或改期後會同步更新投影。

## 操作步驟

- 首頁可查看未讀通知與近期行程。
- 從會員中心或首頁卡片開啟 `calendar` 查看日期、來源與事件詳情。
- 從通知或行事曆事件進入對應訂單，查看 StatusEvent 時間軸。
- 訊息可標記已讀；站內通知與交易狀態分開呈現。

## 限制與 Demo 標示

AIWave 行事曆是平台 projection，不是 Google／iCloud 的完整替代品。競賽 Demo 主要使用持久化站內通知，不宣稱已接正式外部推播或日曆同步。

## 導覽 action

可前往 `calendar` 查看行程、`orders` 查看訂單或 `home` 回到會員總覽。

## 版本與來源

本說明對應 app version `0.1.0`；更新日期 2026-08-01。
