# 中元普渡準備

## 使用邊界

這是一份由 AIWave 團隊為競賽展示編寫、人工檢視過的 Demo 指南，不是政府公告、宗教機構意見或採購清單。中元普渡涉及地域、宗教與家庭差異；使用前要以家庭、社區與所在地規範為準。本文不包含商品 SKU、價格、庫存、門市或自動下單。

## 建議步驟

1. 先確認家人是否參與、日期、地點與社區公共區域規則。
2. 把「家中已有」與「仍需準備」分開，不要把便利或合作推薦誤標成必要。
3. 依人數、場地與保存方式建立一份可修改的準備清單。
4. 活動前再次確認時間、天候、食物保存與垃圾處理安排。

## 通用準備分類

- 常見必要：依家庭與場地規範確認供桌／容器、飲水與清潔用品。
- 可選：依家庭習慣準備水果、點心或簡單供品；不代表所有家庭都需要。
- 便利：標籤、收納袋、濕紙巾等可讓整理更容易，但不影響活動是否完成。
- 合作推薦：若平台另有社區服務，只能獨立標示「合作推薦（非必要）」；不得混入一般必要清單。

## 警示

- 不同家庭、宗教與社區規定可能不同；不確定時先詢問家人或管理室。
- 食品、香火、用火與公共空間使用要遵守當地安全規範。
- 「幫我準備」只會整理上述類別與 Demo 點數估算，不會建立訂單或代替會員同意採購。
