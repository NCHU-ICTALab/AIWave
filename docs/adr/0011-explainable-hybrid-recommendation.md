# 推薦採可重算特徵計分與 AI 理解/解釋的混合管線

官方資料只有 99 筆訂單與 10 個帳號，不足以合理宣稱訓練出成熟的機器學習推薦模型；但若完全交給 LLM 自由推薦，又無法重算、驗證或說明依據。我們決定先把訂單、表單、對話意圖與偏好整理成行為軌跡及可重算特徵，依最近性、頻率、週期、時間、天氣、限制、推薦回饋與優惠效益產生候選項目及分數，再由 AI 理解當下語境、協助排序並將既有證據轉成自然語言。每項推薦必須攜帶 reason codes、證據與資料時間；使用者以「不感興趣」和復原逐步調教服務、商品、品牌或主題偏好，負向訊號可隨時間及新行為調整，不等同硬性禁忌。未來資料量足夠時，可在不改動上層契約的前提下替換成協同過濾或學習排序模型。
