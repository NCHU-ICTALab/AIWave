# 今日生活中心：八種 UI 方向

這是方向選擇用的獨立 HTML 原型，不是正式 Vue 應用。開啟 `index.html` 後可切換八種視覺方向及桌機／手機預覽；「不感興趣／復原」可測試推薦回饋狀態。

共同內容刻意固定，差異只放在排版、密度、色彩、形狀及視覺節奏：

1. 理性企業（Grid Trust）
2. 溫暖生活（Warm Care）
3. 智慧零售（Retail Pulse）
4. 數據管家（Data Concierge）
5. 精緻極簡（Calm Premium）
6. 臨床零售（Clinical Retail）：03 的資訊節奏＋02 的圓角＋使用者提供的 frosted-paper 元件規則
7. 生活指揮台（Bridge Ops）：移植 `variant-b-bridge-ops.html` 的頂部步驟導覽、實邊儀表與決策節奏，內容改為生活服務
8. 柔和指揮台（Soft Ops）：07 的資訊架構＋06 的圓角與生活感，陰影全面改為中性黑

06 另提供五組色票（青綠暖黃／鈷藍杏橘／森林蜜桃／磚紅霧藍／深靛萊姆），並將主導覽改為頂部 bar；手機版使用兩列頂部導覽。

原始 `variant-b-bridge-ops.html` 保留作為視覺來源，不會混入船舶資料或取代生活服務需求。

08 提供 07 青綠琥珀、暖灰墨綠、燕麥霧藍、米白陶土四套 token；僅改變色彩，不改變版面，且都不使用彩色陰影。07 青綠琥珀為目前預設。

姓名、點數、折扣及日期皆為示意資料。正式方向選定後，再取得平台名稱、Logo、色票與合作品牌官方資產，建立 `brand-spec.md`，並把選定 token 與元件轉成 Vue 3。
