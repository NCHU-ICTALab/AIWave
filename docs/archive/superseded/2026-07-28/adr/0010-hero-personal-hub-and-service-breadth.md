# Hero、今日生活中心與廣服務目錄構成競賽版展示

原始需求橫跨個人、家庭、社區、零售與廠商，若每條情境平均分配 Demo 時間，核心價值會失焦；若介面只呈現冷氣清洗，又會像單一服務預約網站。我們決定以「DUSKIN 社區冷氣聯合清洗」作為端到端 Hero Demo，以個人「今日生活中心」作為第二條主要展示線，整合可解釋推薦、消費與點數優惠、提醒及跨服務訂單；同時讓官方 8 項服務與實際訂單中的商城購物共 9 項都達到可操作標準，並將 DUSKIN、黑貓、foodomo、EZTABLE、7-ELEVEN 五條品牌服務做較深整合。健康、旅遊、考試週等需求保留為共用推薦與任務引擎上的情境模板，不各自建立獨立系統。
